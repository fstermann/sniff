# Rule explorer

Browse the complete bundled registry or choose a profile to inspect the rules selected for LLM
evaluation. Open any rule for its metadata and full guidance. Prompt preview is the exact text
emitted by `sniff rules --profile <profile>` using bundled defaults.

!!! note

    Project and user configuration can change rule selection and severity. Use the CLI with
    `--target` to preview the effective bundle for a particular project.
